# 播放器可用性验收标准（ACCEPTANCE） — V0.3 P4

> 目的：为 MeloX 定义「逐字歌词对齐是否达到播放器可用」的研发验收标准。
> 本轮**不**做 Android 集成、不做全模型量化、不做 UI。
> 所有结论基于 **`lrc_only`（盲评）** 模式；`oracle` 模式仅用于声学算法研究，不作为验收依据。

## 1. 评测条件（必须）

| 项 | 规定 |
|---|---|
| 输入 | 音频 + 歌词文本 + **LRC 行起始时间**（模型推理不得使用人工标注边界） |
| 参考 | 仅评估阶段使用（GTSinger 词/字边界） |
| 模式 | `lrc_only` 为主；`oracle` 单独报告，绝不与盲评混合 |
| 划分 | 按歌手 / 歌曲隔离报告，避免未来域适配与评测泄漏 |
| 引擎 | heuristic（基线）、model、model+energy、model+reseg |

## 2. 建议验收阈值（待与产品确认）

面向「卡拉 OK 式高亮」体验，暂定以下目标（`lrc_only`、中文/英文主要语言）：

| 指标 | 目标 | 说明 |
|---|---|---|
| 覆盖率 | ≥ 0.95 | 成功匹配的参考单元比例 |
| 段落失败率 | ≤ 0.05 | 模型拒绝输出（塌缩/不可行）的比例 |
| start 中位误差 | ≤ 0.15 s | 逐单元起始 |
| start P90 误差 | ≤ 0.40 s | |
| end 中位误差 | ≤ 0.20 s | |
| end P90 误差 | ≤ 0.50 s | |
| 不确定边界比例 | 报告并为 0（CJK 多字 token 除外，需单独列出） | |

> 阈值是**研发目标**，不是已达成结论。是否达成见 `docs/EXPERIMENT_RESULTS.md`。

## 3. 必须回答的 5 个问题

1. **中文模型在真实 LRC 条件下是否仍明显优于启发式？**
   → 见 `EXPERIMENT_RESULTS.md` §V0.3（zh / lrc_only）。
2. **日语失败是模型问题，还是对齐算法 / 歌词处理 / 窗口策略问题？**
   → 见 `EXPERIMENT_RESULTS.md` §日语诊断 与 `diagnosis_ja.json`。
3. **英文起始时间能否获得稳定改善？**
   → 见 `EXPERIMENT_RESULTS.md` §英文起始（必须同时报告 start 与 end）。
4. **哪种模型最值得继续移植到 Android？**
   → 见 `ANDROID_FEASIBILITY.md` 与 `EXPERIMENT_RESULTS.md`。
5. **哪些算法或模型需要放弃？**
   → 见 `KNOWN_LIMITATIONS.md`。

## 4. 泄漏与划分政策

- 若未来做歌声域适配（例如用 GTSinger 训练集微调），必须**按歌手/歌曲隔离**训练与评测；
  本轮评测集仅用于评估，不参与任何训练。
- 报告强制包含 `by_singer` / `by_song` / `by_technique` 三组拆分（见 `singing_*.json`）。

## 5. 本轮明确不做

- 不做 Android App / Compose UI / MeloX 集成。
- 不做全模型量化（仅在 `ANDROID_FEASIBILITY.md` 讨论）。
- 不把未经验证的模型当作正式发行模型。

## 6. 本轮验收结论（`lrc_only` 盲评，2026-10 实测）

| 指标 | 目标 | zh `fa-zh` | en `wav2vec2-base` | ja `reazon-base` |
|---|---|---|---|---|
| 覆盖率 | ≥ 0.95 | 1.000 ✅ | 1.000 ✅ | 0.528 ❌ |
| 段落失败率 | ≤ 0.05 | 0.000 ✅ | 0.000 ✅ | 0.467 ❌ |
| start MAE | ≤ 0.15 | 0.141 ✅ | 0.138 ✅ | 1.248 ❌ |
| start P90 | ≤ 0.40 | 0.220 ✅ | 0.280 ✅ | 4.121 ❌ |
| end MAE | ≤ 0.20 | 0.198 ✅ | 0.114 ✅ | 1.291 ❌ |
| end P90 | ≤ 0.50 | 0.511 ⚠️(略超) | 0.250 ✅ | 4.121 ❌ |

**结论**：
- **中文、英文达到播放器可用目标**（英文全项达标；中文仅 end P90 略超 0.50）。
- **日文不达标**，根因是声学模型与歌声域失配（见 `EXPERIMENT_RESULTS.md` §4）。
- 该验收为**段级**结论；整曲（多行 LRC + 长时间轴）仍需下一阶段验证。
