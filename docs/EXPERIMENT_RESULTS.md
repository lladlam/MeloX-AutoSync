## 3. 实验 B：已知文本强制对齐

### 3.1 英文合成样本（精确词边界）

方法：用 `espeak-ng` **逐词**合成后按已知静音间隔拼接，因此每个词的起止时间**精确已知**（`tools/make_synthetic_sample.py`）。文本 `"hello world this is a test"`，6 词。

| 引擎 | start MAE | start 中位 | start p90 | start max | end MAE |
|---|---|---|---|---|---|
| 启发式（均分，基线） | 0.342 s | 0.387 s | 0.548 s | 0.596 s | 0.449 s |
| **模型（wav2vec2 + Viterbi）** | **0.067 s** | **0.067 s** | **0.098 s** | **0.109 s** | 0.394 s |

结论：
- 模型起始对齐精度显著优于启发式（**67 ms vs 342 ms**）。
- 结束时间在 espeak 合成语音上系统性偏早约 0.39 s（见局限性分析）。

### 3.2 英文真实语音（LibriSpeech `sample1.flac`）

- 13.69 s 真人语音，已知文本 42 词。
- 结果：42 个单元，时间**严格单调、无重叠**，覆盖 0.18 → 13.46 s。
- 词时长合理（`GOING` 0.24 s、`SLUSHY` 0.40 s…），首词接近语音起始、末词接近语音结束。
- **无人工词边界标注**，因此这里只做**定性/一致性**验证，不报告误差数字。

### 3.3 中文合成样本（精确字边界）

方法同上，`espeak-ng -v cmn` 逐字合成 `"巨龟是科隆群岛的食草动物"`（12 字），用 `fa-zh` 对齐。

| 指标 | 值 |
|---|---|
| start MAE | 0.502 s |
| start 中位 | 0.181 s |
| start p90 | 1.090 s |
| end 中位 | 0.296 s |

结论：中位误差尚可（0.18 s），但存在明显离群（p90 > 1 s），归因于 **espeak 合成中文与真人训练域的差异**。

### 3.4 真实日语 / 中文语音（FLEURS，定性）

- 日语 `fleurs_ja_sample.wav`：19 个单元覆盖 0.0–7.96 s、单调；模型 CTC 转写与参考高度接近（局部错字）。
- 中文 `fleurs_zh_sample.wav`：35 个汉字覆盖 0.67–7.01 s、单调，逐字时间合理。
- 这两者**无人工边界标注**，仅作管道正确性与合理性验证。

## 5. 结论

1. 三语言**均可真正加载并推理**，输出逐单元时间轴 JSON。
2. 英文强制对齐起始精度已达 **~67 ms**（合成标注），真实语音结构合理。
3. 中文 `fa-zh` 提供**汉字级**原生时间戳，管道正确。
4. **尚未验证**：真实歌声、伴奏干扰、拖音/连唱（实验 C/D）。
5. espeak 合成语音的结束时间偏早，主要受**域不匹配**影响，真实语音上明显缓解。
