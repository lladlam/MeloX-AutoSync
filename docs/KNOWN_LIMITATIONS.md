# 已知限制与未解决问题（KNOWN_LIMITATIONS）

> 诚实清单：哪些没做完、哪些不可信、哪些有风险。数字依据见 `docs/EXPERIMENT_RESULTS.md`。

## 1. 已验证的歌声结果（真实 GTSinger）

- 中文 `fa-zh` 在歌声上**明显优于启发式**：start MAE 0.151 s vs 0.539 s，覆盖率 100%。
- 英文 wav2vec2 的**结束**边界优于启发式（0.150 vs 0.309），**起始**反而更差（0.367 vs 0.326，P90 1.0 s）。
- 日文模型在 **9/18 段**塌缩并被正确判为失败，有效段精度良好但**覆盖率仅 0.489**。

## 2. 仍未完成 / 不可信的部分

- **真实伴奏混音未验证**：MIR-1K 下载链接 404，无其它可授权伴奏。§5 的伴奏实验是**自合成床**，掩蔽有限，不能代表真实商业混音。
- **日文歌声可用性差**：约一半段落在 reazon 语音模型上塌缩。当前只能「报告失败」，无法对齐。
- **英文起音定位不稳定**：拖长音的 word 起始有 ~1 s 级误差，且起始吸附改进被否决。
- **数据集规模小**：每语言仅 6–18 段、单一歌手、曲目有限；不足以估计真实歌曲的总体分布。
- **未覆盖唱法**：没有 rap / 快速连唱 / 强颤音类样本。

## 3. 算法与流程限制

- **按行独立对齐**：行间无全局约束；跨行拖音可能被切断。
- **末行窗口延伸到音频末尾**：长尾奏会产生大量 blank 帧（结果正确但浪费算力）。
- **CTC 塌缩阈值**：`单 token > 50% 帧` 判为塌缩。合法情况下若确有一个超长单音（如整段一个「啊」），也可能被误判——但目前样本未出现。
- **日文 token 粒度**：一个 token 可能是多字词（如 `世界`、`あり`），其内部边界标记 `uncertain=True`，**不假装可精确切分**。
- **英文单元文本**：以原词为主，标点/大小写映射在数量不匹配时回退到规范化文本。
- **启发式已显式标注**：`source="heuristic"`，绝不冒充模型结果。
- **未做量化**：均为 FP32。

## 4. 依赖与合规限制

- **内存**：歌声基准峰值 0.99–1.21 GB。
- **中文依赖重**：`funasr` extra 引入 scikit-learn / sentencepiece / oss2 / librosa 等。
- **中文许可证**：`funasr/fa-zh` 为 FunASR Model License（other），商业分发前须复核。
- **数据集许可证**：GTSinger 为 CC BY-NC-SA 4.0（非商业、ShareAlike）；OpenCpop 为 CC BY-NC-**ND**（我们的派生对齐结果受 ND 限制，故未采用）。原始音频与派生标注**均未提交到本仓库**。
